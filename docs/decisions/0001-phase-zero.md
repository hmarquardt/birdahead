# ADR 0001 — Phase Zero boundary and evidence

Date: 2026-11-15. Status: accepted from owner instructions.

BirdAhead's main risk is a reliable, lawful and economically reviewable dataset. Authorize bounded research, repository documents, minimal tooling and the single specified domain purchase. Defer application implementation, paid infrastructure, bulk ingestion and deployment until owner review.

Record observed results separately from documented capabilities, assumptions and blocked work. A submitted registration or HTTP 200 response is not proof of success. The domain workflow and separate active-resource read were both verified; acquisition challenges and throttling remain failures in the experiment record.

Consequence: Phase Zero can end with a conditional recommendation and unresolved access/review gates. Do not manufacture approval rates, annual frequency profiles or coverage in order to mark feasibility complete.
