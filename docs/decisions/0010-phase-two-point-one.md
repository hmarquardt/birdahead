# ADR 0010 — Complete the initial collection with bounded replacement

Date: November 15, 2026. Status: implemented within the Phase 2.1 local authorization.

Resume the existing acquisition checkpoint rather than restarting. Use successive bounded batches with a cumulative 5 GB new-media budget, explicit request/retry limits, cached source responses, no re-download of known rejected URLs, and bounded four-worker media transfers while metadata requests remain provider-paced. Verify free disk space before starting.

Use 5-photo/3-recording candidate targets for the remaining breadth pass, then a 12/8 candidate replacement pass on high-priority, pilot and confusion-pair species with accepted-coverage gaps. Replacement begins on later result pages and still passes every rights, provenance, source-support, technical, deduplication and model gate. Candidate counts are never accepted coverage. Reuse BioCLIP/BirdNET predictions when model/preprocessing versions are unchanged; re-run only new assets and verified clips.

Prepare a compact delivery-object manifest for an eventual authenticated household R2 bucket; do not upload or deploy. Retain per-object license/attribution and explicitly report NC/SA restrictions and projected storage. Prepare a concise risk-stratified sampled audit queue; no human/expert approval is fabricated and the two-hour owner-review cap remains untouched.

No paid inference, additional county download, large geographic dataset, production deployment or cloud resource is authorized. [Phase 2.1 report](../phase-two-1.md).
