# Local learner MVP

November 15, 2026. Implemented and authorized under the Phase One amendment. This is the learner experience, separate from the curation workbench. No cloud resource, hosting registration, authentication service or deployment was created.

## Start and use

From the repository root, run the commands in [README](../README.md#try-the-local-learner). `tooling.teaching_universe` derives the 100-species priority list offline; `tooling.histograms` reads the seven private originals and the existing cached taxonomy; `tooling.local_release` re-exports current independent rights/biology decisions, checks media hashes and compiles a private v2 release. `tooling.expansion status` reports the resumable Phase Two acquisition checkpoint without contacting a source. It never calls a media API or loads credentials. `npm run local --prefix app` checks TypeScript, compiles React/Vite and starts a loopback Hono server at **http://127.0.0.1:8788**. Ctrl-C stops it. `npm start --prefix app` reuses a current build. Node 26 was measured; Node 22.13+ is required for the SQLite adapter.

Select Birder 1 or Birder 2, county and outing date. Here Now ranks current historical relevance; Arriving Soon separately sorts positive rises in the next 14/21/28 days, including zero current reporting. Reinforcement uses prior mistakes/uncertainty and a simple exponential due interval. These are transparent practice heuristics, not validated learning optimization or ecological probabilities. More than one accepted example is required per species/modality; examples do not repeat within a session, and less-seen examples are preferred between sessions. Confusions supply useful distractors. Recognition/recall and photo/audio attempts are stored separately. Recall is self-rated.

A session ends at ten available examples or five minutes, whichever comes first. Source/credit/license links are available before answering, and full attribution appears at reveal. Photographs use original bytes; the optional outline indicates the screened target. No sex/age/plumage or vocalization detail is invented. “I’m not sure” and “Not enough information” are uncertain outcomes rather than successes or incorrect species guesses. Current decisions are automatically accepted and source/model corroborated; no owner/expert certification is claimed.

The release carries the 100-species teaching universe and **193 accepted assets** (141 photographs, 52 recordings), including 24 verified audio clips. Practice requires at least two accepted examples per species/modality: 30 species are sight-ready and 16 sound-ready; four meet both the five-photo and three-recording targets, and 68 remain explicit gaps. The five-photo/three-recording target is a coverage objective, not a gate. The preparation view, field guide and coverage view expose counts, targets and gaps explicitly. Difficult hawk, woodpecker and yellowlegs comparison coverage remains where media evidence supports it; weak examples are not promoted to fill a cell.

## State, flags and portability

- Compiled content: ignored `experiments/private/local-mvp/release.json`, content-addressed from source profiles and the approved manifest. It carries data vintage, sample-support semantics, coverage tiers, priority ranks and a stable compatibility key. Original media remain in the existing private media directory.
- Learning: ignored `experiments/private/local-mvp/learning.sqlite` with profiles, sessions, attempts and identification flags. SQLite is portable. Export a consistent live backup using Python's `sqlite3.Connection.backup`; copy associated media/release privately with required licenses if permitted. Do not commit any of these. Close the app before relocating all original SQLite files or resetting state.
- Flags preserve reporter/profile, asset, content release, session, reason, optional suggested species and timestamp. Reporting hides the asset from **both** learners immediately, skips it in active practice and excludes all related attempts from progress. A report is not proof of a biological error. It does not silently grant rights/biological approval or erase history. Flags survive content rebuilds because they live outside the compiled release. Reconcile them into the local workbench with `uv run python -m tooling.flag_sync --apply`; each new report appends one deferral event for triage, preserves the report context, and consumes no owner-review seconds. Do not remove a flag just to restore coverage.
- After a workbench quarantine, rights revocation or other curation change, rerun `tooling.local_release` and restart the learner. The running server holds an immutable release in memory; curation edits do not hot-reload. In-app flags suppress immediately without a rebuild.
- A content rebuild with the same compatibility key (same taxonomy authority/version and source scope) preserves active sessions and learner progress; additive species or media do not invalidate them. Removed media are skipped. A scope/taxonomy change requires a fresh session. Learning attempts preserve their original session/release relation. No mastery claim is made from repeated media.
- Two profiles provide independence, not authentication or privacy against another person using this computer. There is no cloud sync. The server accepts loopback Host values, same-origin JSON writes, bounded request bodies and content checksums; media paths are resolved under private storage. Original source links are external navigations, not runtime acquisition.

For a safe reset, stop the server and move the learner database and any `-wal`/`-shm` sidecars into a private backup directory; restart to create fresh learner state. Preserve flagged-media records during normal upgrades. The curation database and owner review budget are not reset by learner operations.

## Verification

`npm test --prefix app` exercises real Hono handlers against synthetic content: independent profiles, directed confusion, idempotent answers, invalid dates, recall self-rating, expiry, flag suppression/progress repair, provenance, library/coverage views, compatible-release continuation, feedback context and cross-origin rejection. Python tests add teaching-universe derivation, interrupted/resumed acquisition, release validation and flag reconciliation. `uv run --with playwright python -m tooling.learner_browser_smoke` launches a disposable private learner database with the real accepted release. It checks seasonal changes, independent approaching priorities, actual image decoding, real muted audio playback/ranges, uncertainty, reload continuation, two profiles, flagging, field-guide search/gallery, seasonal coverage, recall and mobile layout. It never adds owner attempts or review minutes. Evidence is [the browser report](../experiments/local-mvp-browser.json); screenshots remain private.

Future work: sampled biological audits and stronger coverage, explicit low-support UI, correction/triage integration, better spaced repetition and unseen-example evaluation. Phone access, installed PWA/offline packs, authenticated cloud sync, shared sessions and road-trip mode are subsequent phases. Bulk geographic access is **not** a gate to using this local app.
